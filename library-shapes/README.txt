FORMES SVG (Inkscape) — dossier library-shapes/
===============================================

AUCUN JSON À ÉDITER À LA MAIN
-----------------------------

1. Inkscape → Enregistrer sous → Plain SVG (*.svg)
2. Copiez le .svg dans CE dossier (library-shapes/)
3. Double-cliquez MAJ-formes.bat  → catalog.json est regénéré automatiquement
4. Rechargez l'éditeur (ou bouton 🔄 dans Bibliothèque)

ALTERNATIVES SANS BAT
---------------------
- Glissez des fichiers .svg dans la zone Bibliothèque (import immédiat)
- Bouton « Fichiers SVG… » ou « Dossier… » dans le panneau Bibliothèque

FICHIER catalog.json
--------------------
Généré automatiquement par generate-shape-catalog.ps1 / MAJ-formes.bat
Ne pas modifier à la main sauf styles par défaut (optionnel).

APRÈS DÉPÔT SUR LE CANVAS
-------------------------
- Taille      : Ctrl+T ou « Redimensionner »
- Forme       : poignées blanches
- Épaisseur   : Contour (px)
