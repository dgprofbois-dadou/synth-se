BIBLIOTHÈQUE PERSONNELLE — dossier library-presets/
==================================================

Modèles de style (champs texte + hotspots) partagés via GitHub Pages.

MISE À JOUR DU CATALOGUE
------------------------
1. Dans l'éditeur → panneau Bibliothèque → bouton « catalog.json »
   (télécharge le fichier avec vos modèles locaux + ceux déjà sur GitHub)
2. Remplacez library-presets/catalog.json par le fichier téléchargé
3. Commit + push sur GitHub
4. Rechargez l'éditeur (ou bouton 🔄 à côté de catalog.json)

PREMIÈRE FOIS
-------------
Si vous aviez déjà des modèles enregistrés dans le navigateur (localStorage),
exportez catalog.json une fois pour les mettre sur GitHub.

CONTENU
-------
Chaque entrée : id, kind (box|hotspot), name, createdAt, data (style uniquement).
Pas de réponse ni d'infobulle pédagogique.
