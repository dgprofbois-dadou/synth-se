CONSIGNES VOCALES (MP3) — dossier FTP
======================================

1. Dans l'éditeur : Configuration de la page → « Voix — dossier FTP »
   Exemple : https://monsite.fr/moodle/voices/

2. Sélectionnez un champ texte → panneau « Consigne vocale » :
   - Fichier MP3 affiché (ex. exercice-ch001.mp3)
   - Texte lu = consigne à enregistrer
   - Identifiant (ch001, ch002…) = partie fixe du nom

3. Règle de nommage :
   {préfixe export}-{identifiant}.mp3
   Préfixe = champ « Préfixe PDF » (barre du haut, ex. exercice)
   Identifiant = ch001, ch002… (auto à la création du champ)

4. Déposez chaque MP3 sur votre FTP dans le dossier indiqué.

5. Bouton « Liste des MP3 à produire » = inventaire complet avec textes.

6. Mode Élève : clic/focus dans le champ → lecture du MP3 correspondant.

Exemple :
  Préfixe : exercice
  Champ identifiant ch003
  → fichier : exercice-ch003.mp3
  → URL : https://monsite.fr/moodle/voices/exercice-ch003.mp3
